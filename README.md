# side-projects

Small personal projects, prototypes and experiments — no long-term maintenance guarantees. Each file/folder is a standalone mini-project.

> ⚠️ These are experimental and vibe-coded: use them at your own risk!

## Usage

Each project is self-contained (no build, no server). Download the file and open it, or follow the instructions in its own guide.

| Project | Description | |
|---|---|---|
| **Classeur de films 🎬** | Single-file web app to import a Letterboxd export and sort films into custom rating tiers, with TMDb search/posters, drag-and-drop reordering, CSV export/import and shareable Top 10/25 images | [Download](https://raw.githubusercontent.com/PyroDzeus/side-projects/main/classeur-films-v2.html) |
| **NFO Studio 🎞️** | Single-file desktop app (Python) that builds release-style `.nfo` files from MediaInfo: 5 layouts, custom ASCII headers, drag-and-drop and batch saving. [Guide](nfo-studio-README.md) | [Download](https://raw.githubusercontent.com/PyroDzeus/side-projects/main/nfo-studio.py) |
